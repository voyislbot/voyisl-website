VT-Navigara

Universal Software Architectures

VT-Navigara's two universal software architectures comprise the VT-Fundra Foundational Adaptation Architecture and the VT-Bridgara Function Enablement Architecture. They reconcile differences among operating systems, SoC platforms and other hardware, enabling proprietary software algorithms to be ported across SoC platforms, vehicle models and application scenarios with minimal redevelopment.

VT-Navigara

Universal Software Architectures

VT-Navigara's two universal software architectures decouple hardware adaptation from function development, enabling algorithm development independently of hardware environments and promoting software reuse across operating systems, vehicle models and application scenarios.

VT-Bridgara
Function Enablement Architecture

Proprietary middleware, standardized interfaces, reusable algorithms and diversified software portfolios supporting multiple functions. It composes proprietary algorithms into modules supporting NOA, APA, RPA, HPA, AVP, TJP and HWP, and deploys them across operating systems, vehicle models and application scenarios.

VT-Fundra
Foundational Adaptation Architecture

A proprietary hardware abstraction layer, device drivers and underlying resource management software. It decouples software from hardware, enables algorithm development independently of hardware environments and supports migration across different SoC platforms.
