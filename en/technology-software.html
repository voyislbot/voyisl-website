Universal Software Architectures

VT-Navigara's two universal software architectures comprise the VT-Fundra Foundational Adaptation Architecture and the VT-Bridgara Function Enablement Architecture. They reconcile differences among operating systems, SoC platforms and other hardware, enabling proprietary software algorithms to be ported across SoC platforms, vehicle models and application scenarios with minimal redevelopment.

VT-Navigara

Universal Software Architectures

VT-Fundra and VT-Bridgara connect underlying hardware and operating environments with functional algorithms, enabling proprietary software to migrate across SoC platforms, operating systems and vehicle models with limited modification and to be reused across intelligent driving, intelligent cockpit and non-automotive applications.

VT-Bridgara
Function Enablement Architecture

Comprises middleware, standardized interfaces and a library of reusable software and algorithm modules. The middleware provides data access, inter-module communication and service invocation, while standardized interfaces define data inputs, outputs and interactions so algorithms developed for one model can be reused and reconfigured for others.

The reusable library covers calibration, visual perception, fusion positioning and mapping, planning, decision-making and control, and can compose modules supporting NOA, APA, RPA, HPA, AVP, TJP and HWP. Industry-standard components such as AUTOSAR can be integrated.

VT-Fundra
Foundational Adaptation Architecture

Comprises a hardware abstraction layer, device drivers and underlying resource management software, decoupling upper-layer algorithms from specific hardware and operating environments. The HAL routes requests for camera images, IMU measurements, vehicle-network messages and computing resources, while resource-management software allocates computing power, memory and communication bandwidth according to real-time requirements.

The architecture can integrate hypervisors, bootloaders and board support packages to provide the foundation for operating-system execution, system isolation and migration across SoC platforms.

REUSABLE ALGORITHM LIBRARY

Reusable Algorithm Library

Path Planning

Optimal path planning

Evaluates forward, reversing and turning manoeuvres against vehicle pose, heading, steering constraints and surrounding obstacles to generate executable, collision-avoiding parking routes.

Fusion Positioning

Multi-sensor fusion

Fuses IMU, geomagnetic, pressure, camera, millimetre-wave radar, ultrasonic and GNSS information and associates detections of the same object across sensors for greater continuity in complex conditions.

Adaptive Control

AI-powered adaptation

Evaluates driving performance from speed, following distance and acceleration patterns, then adjusts control parameters in real time within pre-established safety boundaries to suit the driving scenario and driver style.

BEV

BEV perception, localization and calibration

Uses a unified top-down 3D representation of the vehicle surroundings to support occluded-object inference, consistent cross-view detection, BEV SLAM localization and mapping, and dynamic calibration while driving.

Intelligent Interaction

Cabin and visual interaction algorithms

For IMS, detects fatigue and distraction and coordinates cabin functions; for CMS, improves low-light imaging, identifies blind spots, enhances adverse-weather images and adjusts brightness adaptively.
