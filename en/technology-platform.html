Technology Platform

VT-Navigara is an algorithms-based, software-hardware integrated infrastructure comprising two universal software architectures, the VT-Fundra Foundational Adaptation Architecture and the VT-Bridgara Function Enablement Architecture, and three software-hardware integrated modules: VT-Sensing Visual Perception, VT-Navi Multi-Sensor Fusion Positioning and Navigation, and VT-Vulcan® Planning and Control.

Technology Platform

VT-Navigara

VT-Navigara is an algorithms-based, software-hardware integrated infrastructure comprising the VT-Fundra foundational adaptation architecture and the VT-Bridgara function enablement architecture, together with VT-Sensing visual perception, VT-Navi multi-sensor fusion positioning and navigation, and VT-Vulcan® planning and control modules. The platform decouples algorithms from hardware and operating environments and combines modules to support customizable functions and scalable mass-production delivery while reducing repetitive component-level adaptation.

Universal Software Architectures

VT-Bridgara
Function Enablement Architecture

Comprises middleware, standardized interfaces and a library of reusable software and algorithm modules. It composes proprietary algorithms into modules supporting NOA, APA, RPA, HPA, AVP, TJP and HWP and deploys them across operating systems, vehicle models and application scenarios.

The middleware acts as a common software bridge between the operating system and functional algorithms, while standardized interfaces allow software developed for one vehicle model to be reused and reconfigured for others. Industry-standard components such as AUTOSAR can also be integrated.

VT-Fundra
Foundational Adaptation Architecture

Comprises a hardware abstraction layer, device drivers and underlying resource management software. It decouples VT-Bridgara software from underlying hardware and operating environments, supporting independent algorithm development and migration across SoC platforms.

The resource-management layer allocates computing power, memory and communication bandwidth according to real-time requirements and can integrate hypervisors, bootloaders and board support packages to support operating-system isolation and platform migration.

Software-Hardware Integrated Modules

VT-Sensing

Visual Perception

Software-hardware integrated camera modules for surround, front, side-rear and in-cabin monitoring.

PLATFORM CHARACTERISTICS

Platform Characteristics

Replicable

Cross-scenario module reuse

Integrated modules and algorithms can be flexibly applied across solutions, vehicle models and application scenarios, reducing the need to rebuild the technology architecture for each project.

Iterative

Independent module evolution

Hardware-software modules and algorithms can be iterated separately in response to underlying technology innovation and customer feedback.

Scalable

Cost-efficient platform migration

Customer-specific solutions can be configured by selecting and adapting existing modules, supporting migration across SoC platforms and operating systems and shortening development cycles.
